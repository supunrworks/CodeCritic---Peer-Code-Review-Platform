# CodeCritic

CodeCritic is a peer-to-peer code review platform where developers can share code snippets, ask for feedback, and review other developers' work. The app is designed to help people improve their coding skills by getting structured feedback on readability, architecture, bug handling, and overall quality.

## Tech stack

### Frontend
- Next.js
- React
- Tailwind CSS
- shadcn/ui components
- lucide-react icons
- Clerk for authentication

### Backend
- Node.js
- Express.js
- Prisma ORM
- PostgreSQL

## Core features

- Submission feed with recent posts
- Per-submission detail page for discussion and review
- User authentication and protected actions
- Karma tracking for review activity
- PostgreSQL-backed persistence with Prisma
- Responsive UI built with Next.js and modern component styling
